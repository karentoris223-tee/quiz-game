# Quiz Game
A simple, fun game where users answer general knowledge questions and get scored instanly.
## Features
  8 general knowledge questions with multiple choices
  Instant feedback on correct / wrong answers
  Final score and performance message
  Easy to extend with more questions
## How to play 
  Read each question and choose A, B, C, or D
  Get instant feedback
  View your final score at the end
